# SyncTube Fresh WebView Experiment

This is a clean, independent Android project created for diagnosis.

- It does not copy or import the previous Android app source.
- It does not depend on Android Browser Helper, Trusted Web Activity, Custom Tabs, Firebase, or the previous splash activity.
- It uses the Android platform WebView directly.
- The test URL is currently https://www.youtube.com/.
- The application ID is com.heroazure.synctube.freshtest, so it installs separately from previous SyncTube test APKs.
- The test workflow only uploads an APK artifact. It does not publish files to the live website.

This is a diagnostic build, not the final SyncTube app.
